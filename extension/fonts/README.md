# Bundled fonts

Latin-subset WOFF2 files from Google Fonts, bundled so the extension never
loads remote assets. All are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling and redistribution.

| File | Family | Used for |
|---|---|---|
| pixelify-700.woff2 | Pixelify Sans | Headings, labels and the main button |
| atkinson-400.woff2, atkinson-700.woff2 | Atkinson Hyperlegible | Body text |
| jetbrains-mono-500.woff2 | JetBrains Mono | Code, traces and the code box |
